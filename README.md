## Sobre o Projeto

Este projeto consiste em uma atividade avaliativa da disciplina de Arquitetura de Sistemas. O objetivo principal foi analisar e refatorar um código-base disponibilizado pelo docente, transformando um sistema simples em uma aplicação bem estruturada. Esta atividade utiliza o código da [Atividade 5](https://github.com/playsonic/sistema-pedidos-eng-reversa/tree/refatoracao-mvc?authuser=2), desenvolvido por mim com a arquitetura MVC, para agora, em sua etapa final, migrar essa estrutura para um modelo estritamente modular, além disso, desenvolver um Diagrama UML e um Fluxo Arquitetural do código.
